JARVIS Social Engine

A personal desktop AI assistant for monitoring authorized social media accounts, reviewing performance statistics and planning content.

Current capabilities

YouTube statistics and read-only calendar access have been tested. TikTok integration is under development in a sandbox. Instagram integration is pending. Public posting is not enabled by this beta connector.

Access

This website provides project information and policies. The application runs locally on the operator’s computer; no public signup is offered.
